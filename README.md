# KSP_PBR_Patcher
A collection of patchers to make supported KSP mods visually coherent with the Technicolor PBR system.
Contains a patcher that adds almost all of the stock parts that ReStockPBR v0.0.6 misses (including robotics), and any other mods I find the time to add support for.

Current mods supported or planned (In various levels of completeness)
 - ReStockPBR_Patch
   - Adds almost all Stock and DLC parts not covered by ReStockPBR
   - Fixes heat tiles part icons for space planes in VAB
   - Fixes some engine parts not being rotated correctly in VAB part icons
   - Adds heat tile variants for two of the mk2 air intakes added by ReStockPlusPBR
   - TODO: Fix dark spots on ISRU texture
   - TODO: Add better texture and possibly model for large rover wheel
 - SCANsat
   - WIP: Reference textures done, need to create patch files
 - CryoTanks
   - WIP: Reference textures done, need to create patch files
 - CryoEngines
   - WIP: Reference textures in progress
 - NFLaunchVehicles
   - WIP: Reference textures in progress

Requirements and Tips:
- In order to run the install script, you'll need python 3.11 or greater, with the following packages installed:
  - `cairosvg`
  - `numpy`
  - `pillow`
  - `pyyaml`
  - `scipy`
  - `texconv-py`
  Technically texconv is optional if you can't find an excutable for it to work on your system, which may or may not be the case on macOS or Linux. 
  If you can't find a version that works on your system, you'll need to find another way to compress the PNG texture files generated by this mod into DDS files.

- Nertea completed a set of pylon textures, but never released them as part of ReStockPBR version 0.0.6.
